# 用語集 中国語 → 日本語（堅守協定:盟約）

翻訳はこの表に従う。**公式** = 日本版の公式データ（`ArknightsGameData_Yostar/ja_JP`）で実際に使われている表記。
**公式(推)** = 日本版の告知・攻略記事に出てくる、または公式の語彙から確実に導ける表記。
**公式(初代)** = 日本版の初代「堅守協定」（検証版）の公式データ（`.cache/gamedata-ja` の activity_table `act1vautochess`）にある表記。盟約版でも同じと見てよい語だけに付けた。盟約版で名称が変わった語（調度センター＝初代では「補給等級」、更新＝「補給の更新」）は、中国語原文が別語なので案のままにしてある。
**案** = 公式の表記を確認できなかったので仮に決めた訳。ゲームを見て直したくなったら、ここと `i18n/ja/*.json` の該当箇所を直す（`node tools/i18n.mjs build` で反映）。

## 表記ルール

- 文体: UI は体言止め・短く（ボタンは名詞または「〜する」）、説明文は「です・ます」でなく常体（「〜する」「〜を与える」）。公式データの説明文に合わせる。
- 数字・単位: 半角数字。「秒」「%」「層」はそのまま。数と助数詞の間に空白は入れない（「3名」「10秒」）。
- 全角記号は原文に合わせる（「：」「（）」「・」）。`{name}` などのプレースホルダと `<@ba.vup>…</>` のようなリッチテキストタグは**原文と同じものを同じ数だけ**残す。
- オペレーター名・敵名・スキル名は日本版公式の名称（`00-official.json` が自動で入れる）。公式に無いものは、中国語名の漢字をそのまま使うか、音訳（カタカナ）にする。
- ボタンや見出しに入る語は短く保つ（レイアウトが崩れやすい）。長い訳は 2 行に収まるか確認する。
- 中国語の固有名詞（デザイン名の「ウォーターブレイク」等）は日本版の公式名があればそちらを使う。
